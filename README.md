# Interactive Portfolio Website

## 📌 Project Title

**Interactive Portfolio Website Using HTML, CSS & JavaScript**

## 📖 Project Description

This project is an interactive personal portfolio website developed using HTML, CSS, and JavaScript.

The purpose of this project is to create a responsive and user-friendly portfolio while demonstrating JavaScript concepts such as DOM manipulation, event handling, form validation, reusable functions, and Local Storage.

The website contains personal information, skills, projects, an interactive image slider, a to-do list, and a contact form.

---

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Listeners
* Local Storage
* Responsive Web Design

---

## ✨ Features

### 1. Dark/Light Mode

Users can switch between dark mode and light mode using the theme button.

The selected theme is saved in Local Storage so that the preference remains after refreshing the page.

### 2. Interactive Image Slider

The project includes an image slider with:

* Next button
* Previous button
* Automatic slide change
* Dynamic image and text updates

### 3. To-Do List

Users can:

* Add tasks
* Delete tasks
* Mark tasks as completed
* Save tasks in Local Storage

### 4. Contact Form Validation

The contact form validates:

* Name
* Email
* Subject
* Message

Error messages are displayed when invalid information is entered.

### 5. Real-Time Validation

The form provides feedback while the user is entering information.

### 6. DOM Manipulation

JavaScript is used to:

* Change text
* Add elements
* Remove elements
* Modify classes
* Update images
* Update styles

### 7. Event Handling

The project uses different JavaScript events including:

* click
* input
* submit
* keypress

### 8. Typing Effect

The home section contains a dynamic typing animation displaying different roles.

### 9. Read More Feature

The About section allows users to show and hide additional information.

## ⚙️ How to Run the Project

### Step 1

Download or clone the project.

### Step 2

Open the project folder in Visual Studio Code.

### Step 3

Make sure the following files are present:

```text
index.html
style.css
script.js
```

### Step 4

Create an `images` folder and add the required images.

### Step 5

Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code.
